# Monarch Lubricating Oil & Grease Company (Kenya)

Official B2B web application for Monarch / Tongyi Lubricants in **Athi River, Machakos County, Kenya** (Near Toptank Greyland & CITAM Church, Off Mombasa Road).

## Setup & Deployment Instructions

### 1. Run Locally
```bash
npm install
npm run dev
```
Visit `http://localhost:3000` in your browser.

### 2. Staff Admin Access
- Access at `http://localhost:3000/admin`
- Authorized Staff Email: `omarkenya4@gmail.com`
- Password: Any password with 6+ characters.

### 3. Deploy to Netlify via GitHub (100% Free)
1. Push this folder to a new GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Monarch Kenya initial commit"
   git remote add origin https://github.com/YOUR_USERNAME/monarch-oil-kenya.git
   git branch -M main
   git push -u origin main
   ```
2. Log into **netlify.com**, select **Add new site > Import an existing project**, and choose this GitHub repository.
3. Netlify will build and deploy it with free global CDN and SSL.
